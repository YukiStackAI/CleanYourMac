# CleanYourMac (Platinum Edition) 🦉✨

A professional, high-fidelity macOS utility application designed to scan, clean, and optimize your Mac with a stunning dark-glass aesthetic and intelligent features.

## 💎 Features

- **🚀 Smart Scan Dashboard:** Full overview of your system's health, scan status, and instant memory diagnostics.
- **🧠 AI Prompt Cleaner:** Locate, filter, and organize files intelligently by simply describing what you are looking for.
- **🧹 Memory Purger:** Fast real-time system RAM purge with smooth visual feedback and live animations.
- **📦 Advanced App Uninstaller:** Safely scan and completely delete application binaries alongside all nested caches and leftover system items.
- **⚡ Startup Manager:** Speed up system boot time by managing launch daemons and user startup items.
- **📊 Real-time Menu Bar Extra:** A gorgeous dropdown bento-grid widget showing live CPU, Memory, Disk Space, and Upload/Download network speeds.

---

## 🛠️ Stack & Architecture

- **Core:** SwiftUI + Native macOS APIs
- **Design System:** Sleek dark-glassmorphic styling, custom palette (Platinum Emerald Green & Cyan), smooth micro-animations.
- **Model:** Local/remote LLM integrations for intelligent prompt analysis.
