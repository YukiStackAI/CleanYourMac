Frequently Asked Questions

Everything you need to know about CleanYourMac Platinum, system requirements, Apple Silicon optimization, and installation instructions.

Is CleanYourMac safe to use?

Absolutely. CleanYourMac is designed with macOS Safety Guidelines. Our platform never deletes user data or crucial system core elements. It safely sweeps cache files, application residues, and crash dumps that are safe to discard.

Does it fully support M1, M2, M3, and M4 Apple Silicon?

Yes! CleanYourMac is compiled natively as a **Universal macOS Binary**. It runs natively on M1, M2, M3, and M4 Max/Pro/Ultra chips as well as legacy Intel-based Macs, delivering incredibly fast, highly optimized system sweeps using minimum system resources.

How does the AI Prompt Cleaner work?

The AI Prompt Cleaner allows you to command your file cleanup tasks using conversational queries! By typing a prompt like *"find installation caches and large video files in Downloads"*, our local intelligence parses the file metadata, isolates them instantly, and lets you wipe them with a single click.

Is the Platinum version completely free?

Yes! Our current Platinum release (Version 1.0.3) is distributed under the MIT Open Source License. You can download and use all premium features (including Smart Scan, Widget monitor, deep uninstallation, and prompt clean) completely free.

How do I uninstall applications cleanly?

Drag-and-drop uninstallation leaves multiple folder structures in your local `~/Library/Application Support/` and `~/Library/Caches/` directories. To uninstall apps cleanly, select the **App Uninstaller** module, choose the apps, and let CleanYourMac locate and wipe all matching registers, settings, and file logs completely.
